# AI Fundamentals Coursework – AAI101 Introduction to AI (DMACC, Fall 2026)

Selected final submissions from Patrick Hall's Introduction to AI course (final grade: A). The two mini-projects have their own repos:
[RetirementHelper chatbot](https://github.com/Escalation2-0/retirementhelper-dialogflow-chatbot) and [Insurance claims fraud analysis](https://github.com/Escalation2-0/insurance-claims-fraud-analysis-orange).

| Folder | What's inside | Tools / concepts |
|---|---|---|
| [`01-generative-ai-comparisons`](01-generative-ai-comparisons/) | Side-by-side tests of ChatGPT vs. Gemini, and Claude vs. Gemini vs. ChatGPT, using the same controlled prompts (explanation, presentation, research paper, app design, poem, translation, market summary), scored on set criteria | ChatGPT, Google Gemini, Claude; prompt design; evaluating accuracy and limits |
| [`02-neural-networks-tensorflow-playground`](02-neural-networks-tensorflow-playground/) | Experiments that change one setting at a time on the circle dataset, recording epochs and test/training loss | TensorFlow Playground; ReLU/sigmoid/tanh; network architecture; learning rate; L2 regularization; noise; overfitting/underfitting |
| [`03-data-literacy-power-bi-airtable`](03-data-literacy-power-bi-airtable/) | A classification report on a small fictional dataset, plus a two-table relational base | Power BI Service (visuals, Sum vs. Average aggregation); Airtable linked tables; classification, clustering, association rules; SQL vs. NoSQL |
| [`04-python-colab`](04-python-colab/) | A completed Python fundamentals notebook, plus a discussion on no-code vs. coding | Python in Google Colab: variables, types, input/type conversion, operators, if statements, lists, tuples, loops, range |
| [`05-ai-ethics-and-applications`](05-ai-ethics-and-applications/) | Discussions on facial-recognition ethics, ML fraud detection in retirement accounts, and the future of AI in finance | Fairness, accountability, transparency; supervised vs. unsupervised vs. reinforcement learning |

**How to view:** open any PDF in the browser. The `.ipynb` notebook renders on GitHub, or you can open it in Google Colab.

**Skills shown:** testing and comparing AI tools against requirements, experiment design and documentation, data analysis and visualization, Python basics, and responsible AI.
