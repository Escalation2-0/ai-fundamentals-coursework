# Exploring Neural Networks with TensorFlow Playground

Module 4 assignment (scored 100/100). I used [TensorFlow Playground](https://playground.tensorflow.org) on the circle dataset, changing one setting per experiment: activation function, architecture, learning rate, L2 regularization, and noise. For each run I recorded the epoch count and test/training loss, then explained the result.

One example finding: on a tiny 2,2 network, none of the activation functions solved the circle, while wider 3,3 and 5,5 networks did. Width mattered more than stacking thin layers.

The full write-up is in [`TensorFlow_Playground_Experiments.pdf`](TensorFlow_Playground_Experiments.pdf), and the screenshots are in [`screenshots/`](screenshots/).
